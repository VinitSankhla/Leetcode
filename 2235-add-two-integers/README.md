# 2235. Add Two Integers

**Difficulty:** Easy  
**Language:** Java  

## Problem Description
Given two integers `num1` and `num2`, return the sum of the two integers.

### Example
- **Input:** num1 = 12, num2 = 5
- **Output:** 17
- **Explanation:** num1 + num2 = 12 + 5 = 17.

## Complexity
- **Time Complexity:** $O(1)$
- **Space Complexity:** $O(1)$
